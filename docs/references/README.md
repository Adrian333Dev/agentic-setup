# References

External resources, technical decisions, and documentation links for this project.

---

## What goes here

| File | Content |
|------|---------|
| `llms.md` | LLM-ready documentation URLs (`llms.txt` / `llms-full.txt`) for tools used in this project |
| `decisions.md` | Architecture Decision Records — significant decisions and their rationale |
| `links.md` | External dashboards, service consoles, runbooks, design files |

---

## Notes

- Keep `llms.md` updated as you add new dependencies — it directly improves AI assistance quality.
- Prefer `llms.txt` / `llms-full.txt` over context7 when available; context7 can have outdated docs.
- `decisions.md` belongs in both `docs/spec/` (product/arch decisions) and here (external references) — use whichever makes more sense for the decision type.
