# LLM-Ready Docs

> Prefer `llms.txt` / `llms-full.txt` over context7 when available — context7 can have outdated docs.

Add an entry for every major library or service used in this project.

---

## How to use

Tell the AI: *"Check the llms.txt for [tool] in docs/references/llms.md"* — or just reference this file at session start.

- **`llms.txt`** — index / summary, fast to load
- **`llms-full.txt`** — complete docs, use when you need deep detail

---

## Finding llms.txt for a library

Check: `https://<docs-domain>/llms.txt`  
Or search: `site:<docs-domain> llms.txt`
